## EXP-001: Crawl4AI Integration

**Статус:** ✅ ЗАВЪРШЕН УСПЕШНО  
**Период:** 04-05 февруари 2026  
**Branch:** `feature/crawl4ai-integration`

### Цел

Тестване на Crawl4AI като алтернатива на Playwright + Claude AI за извличане на продукти и цени. Целта е намаляване на времето за изпълнение и елиминиране на Claude API разходите.

### Хипотеза

Crawl4AI може да извлича структурирани данни от e-commerce сайтове чрез regex patterns, без нужда от LLM анализ, като постига сравнима точност с текущата production система.

### Методология

1. **v1-v5:** Итеративно разработване на extraction patterns
2. **v6.0-v6.2:** Динамично извличане на продукти от Кашон + debug анализ
3. **v6.3 FINAL:** Site-specific extraction patterns за всеки магазин

### Технически детайли

#### Site-specific extraction patterns

**Кашон Harmonica:**
```python
# Markdown links: [Име](https://kashonharmonica.bg/bg/products/...)
pattern = r'\[([^\]]{5,80})\]\(https://kashonharmonica\.bg/bg/products/([^\)]+)\)'
```

**eBag:**
```python
# Alt text: [![Име](img)](url)
# Title with prices: ### [Име Годно до: XX/XX/XXXX X,XX € X,XX лв.]
img_pattern = r'\[!\[([^\]]+)\]\([^\)]+\)\]\([^\)]+\)'
title_pattern = r'###\s*\[\s*([^\]]+?)\s+Годно до:[^\]]*?(\d+[,\.]\d{2})\s*€[^\]]*?(\d+[,\.]\d{2})\s*лв'
```

**Balev Bio Market:**
```python
# Редове с грамаж + EUR/BGN цени в контекста
weight_pattern = r'\d+\s*(?:г|мл|ml|g)\b'
```

#### Dual currency extraction (EUR/BGN)

От юни 2026 всички магазини в България показват цени в двете валути. EUR е водещо.
```python
def extract_eur_price(text):
    match = re.search(r'(\d+)[,.](\d{2})\s*€', text)
    ...

def extract_bgn_price(text):
    match = re.search(r'(\d+)[,.](\d{2})\s*лв', text)
    ...
```

### Изводи

1. **Crawl4AI е жизнеспособна алтернатива** за извличане на данни от български e-commerce сайтове
2. **Site-specific patterns** са необходими — всеки сайт има уникална markdown структура
3. **Динамичното извличане работи** — 79 продукта от Кашон без hardcoded списък
4. **Matching алгоритъмът може да се подобри** — keyword matching постига 23-49%

### Препоръка: Хибриден подход

Предлагаме **хибриден метод** за production:

1. **Ежедневно:** Сканиране с фиксиран списък продукти (бързо, надеждно)
2. **На всеки 4 седмици:** Пълно сканиране на Кашон за нови/отпаднали продукти
3. **При промяна:** Автоматично обновяване на референтния списък

Това комбинира:
- ✅ Стабилност на фиксиран списък
- ✅ Актуалност чрез периодична проверка
- ✅ Нулеви Claude API разходи
- ✅ Бързо изпълнение (~1 мин за 3 магазина)
